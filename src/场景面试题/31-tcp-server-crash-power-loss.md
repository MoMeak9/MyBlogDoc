# 若服务端进程崩溃或突然断电，已建立的 TCP 连接会发生什么情况？

## 一句话答案

服务端进程退出后内核会清理其socket；突然断电或网络隔离时客户端可能暂时保持半开连接，直到通信或保活超时才发现。

## 面试回答要点

- 进程崩溃与整机断电不同：前者内核仍可能发关闭或重置信号。
- 静默连接没有数据交换时通常无法立即确认对端故障。
- 应用层心跳、读写超时和重试可以更快发现并恢复失效连接。
