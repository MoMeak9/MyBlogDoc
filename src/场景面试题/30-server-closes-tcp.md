# 服务端在哪些常见场景下会主动断开 TCP 连接？

## 一句话答案

服务端会因正常业务结束、空闲或读写超时、协议错误、资源保护和优雅停机而主动关闭TCP连接。

## 面试回答要点

- 区分正常FIN关闭与异常RST重置，客户端处理方式不同。
- HTTP keep-alive、连接池和心跳超时通常控制空闲连接。
- 关闭前应处理在途请求并配置合理超时，避免连接泄漏或误断。
