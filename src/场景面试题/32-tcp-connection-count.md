# 一个服务端进程最多可以建立多少条 TCP 连接？一个机器呢？

## 一句话答案

TCP连接数没有统一固定上限，进程受文件描述符约束，机器还受内存、内核参数与应用处理能力限制。

## 面试回答要点

- 每条已建立连接通常占用socket及文件描述符，查看进程和系统两级限制。
- 监听队列容量、吞吐与连接总数是不同指标，应分别压测。
- 主动对外连接还需考虑本地地址端口组合，但不能把临时端口数当成整机所有连接的通用上限。
