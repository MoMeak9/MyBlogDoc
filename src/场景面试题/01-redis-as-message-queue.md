# Redis可以做消息队列吗？什么时候能用Redis做消息队列？

## 一句话答案

Redis能承担轻量消息传递；List、Pub/Sub和Streams的交付能力不同，可靠性要求高时要认真评估持久化、确认和故障切换。

## 面试回答要点

- List适合简单队列，但确认、重试和消费组能力需要自行补齐。
- Pub/Sub是实时广播，订阅者离线时不会补收历史消息。
- Streams提供消费组、待确认消息与确认操作；仍要设计持久化、幂等和灾难恢复。
