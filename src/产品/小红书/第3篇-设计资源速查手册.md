## 🎯 一、图标资源（必备）

### 1. **Iconfont** ⭐⭐⭐⭐⭐
- **网站**：https://www.iconfont.cn
- **特点**：阿里出品、免费、图标数量超多
- **核心功能**：
  - 海量图标库（支持 SVG、PNG、AI 格式）
  - 可自定义颜色和大小
  - 支持生成图标字体
  - 提供官方图标库和设计师上传图标
- **适合场景**：
  - 原型设计配图
  - PPT 演示图标
  - 产品文档插图
- **使用技巧**：
  - 搜索关键词：用中文或英文都可以
  - 加入购物车：批量下载自己需要的图标
  - 项目管理：创建项目分类管理图标

**💡 实用案例：**
```
需求：画一个电商App首页原型
操作：
1. 搜索"购物车" → 选择合适的图标
2. 搜索"首页" → 找导航图标
3. 搜索"搜索框" → 找搜索icon
4. 批量下载 PNG 格式，直接放进 Axure
```

## 🌟 二、设计灵感网站

### 2. **站酷（ZCOOL）** ⭐⭐⭐⭐⭐
- **网站**：https://www.zcool.com.cn
- **特点**：国内最大设计师社区
- **核心内容**：
  - UI设计作品展示
  - 网页设计案例
  - APP界面设计
  - 品牌设计作品
- **适合场景**：
  - 寻找设计灵感
  - 参考同类产品设计
  - 学习设计趋势
- **使用技巧**：
  - 关键词搜索："电商首页设计"、"社交APP界面"
  - 关注优秀设计师，定期看他们的作品
  - 收藏夹分类：按项目类型整理

### 3. **Dribbble** ⭐⭐⭐⭐⭐
- **网站**：https://dribbble.com
- **特点**：全球顶级设计师作品平台
- **核心内容**：
  - UI/UX 设计
  - 动效设计
  - 插画、品牌设计
- **适合场景**：
  - 国际化产品设计参考
  - 高端设计风格借鉴
  - 设计趋势追踪
- **使用技巧**：
  - 英文搜索效果更好
  - 筛选器：选择 UI/UX 分类
  - 订阅 Weekly Warmup（每周设计挑战）

### 4. **牛大拿** ⭐⭐⭐⭐
- **网站**：https://www.niudana.com
- **特点**：设计导航网站
- **核心功能**：
  - 聚合各大设计网站
  - 分类清晰（UI、图标、字体、配色等）
  - 一站式设计资源导航
- **适合场景**：
  - 快速找到各类设计资源
  - 不知道去哪找资源时的第一站
- **使用技巧**：
  - 收藏到浏览器，需要资源时直接打开
  - 按分类浏览：图标、配色、字体、素材

## 📷 三、图片素材网站

### 5. **Pexels** ⭐⭐⭐⭐⭐
- **网站**：https://www.pexels.com/zh-cn
- **特点**：完全免费、高清、可商用
- **核心优势**：
  - 图片质量高
  - 免费可商用（CC0 协议）
  - 支持中文搜索
  - 每周更新数千张新图片
- **适合场景**：
  - PRD 文档配图
  - PPT 演示背景图
  - 产品宣传素材
- **使用技巧**：
  - 中英文搜索结合使用
  - 筛选：选择横向/竖向图片
  - 下载不同尺寸：根据需求选择分辨率

**💡 类似网站推荐：**
- **Unsplash**：https://unsplash.com（国外最大免费图库）
- **Pixabay**：https://pixabay.com（支持图片、视频、音乐）

## 🖌️ 四、图片处理工具

### 6. **Photoshop（PS）** ⭐⭐⭐⭐⭐
- **功能**：图片编辑、抠图、修图、设计
- **适合场景**：
  - 裁剪和调整图片
  - 简单的图片修改
  - 原型配图处理
- **产品经理常用功能**：
  - 裁剪工具：调整图片尺寸
  - 魔棒/套索工具：简单抠图
  - 文字工具：添加文字说明
  - 导出功能：压缩图片大小

**💡 轻量级替代工具：**
- **稿定设计**：在线PS，无需安装（https://www.gaoding.com）
- **Canva**：模板化设计工具（https://www.canva.cn）
- **创客贴**：在线设计平台（https://www.chuangkit.com）

## 📐 五、流程图/绘图工具

### 7. **ProcessOn** ⭐⭐⭐⭐⭐
- **网站**：https://www.processon.com
- **特点**：在线绘图、云端保存、协作方便
- **核心功能**：
  - 流程图
  - 思维导图
  - UML 图
  - 原型图（简单）
  - 组织结构图
- **适合场景**：
  - 业务流程梳理
  - 功能架构图
  - 用户流程图
- **使用技巧**：
  - 免费版限制：9个文件（定期导出备份）
  - 模板库：参考别人的流程图
  - 快捷键：Tab 键快速添加子节点

### 8. **Visio（Windows）/ OmniGraffle（Mac）** ⭐⭐⭐⭐
- **功能**：专业绘图工具
- **适合场景**：
  - 复杂的系统架构图
  - 数据流程图
  - 网络拓扑图
- **特点**：
  - 功能强大、专业级
  - 图形库丰富
  - 导出格式多

**💡 在线替代：**
- **Draw.io**：免费在线绘图工具（https://app.diagrams.net）
- **Excalidraw**：手绘风格流程图（https://excalidraw.com）

## 💡 资源使用技巧

### 📌 场景化资源清单

| 场景 | 推荐网站 | 资源类型 |
|------|---------|---------|
| 画原型需要图标 | Iconfont | SVG/PNG 图标 |
| 找设计灵感 | 站酷、Dribbble | UI 设计案例 |
| PRD 配图 | Pexels | 高清图片 |
| 画流程图 | ProcessOn | 流程图模板 |
| 不知道找什么 | 牛大拿 | 设计资源导航 |

### 🎯 高效使用建议

**1. 建立自己的素材库**
```
- 文件夹分类：图标 / 图片 / 案例 / 模板
- 命名规范：日期_项目_用途（20240104_电商_首页图标.png）
- 定期整理：每月清理未使用的素材
```

**2. 收藏夹管理**
```
浏览器收藏夹结构：
├─ 设计资源
│  ├─ 图标：Iconfont
│  ├─ 灵感：站酷、Dribbble
│  ├─ 图片：Pexels
│  └─ 绘图：ProcessOn
```

**3. 版权意识**
- ✅ Iconfont、Pexels 可免费商用
- ⚠️ 站酷、Dribbble 作品仅供参考，不能直接商用
- ❌ 百度图片搜索结果大多有版权，慎用
