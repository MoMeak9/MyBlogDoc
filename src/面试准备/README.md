## 💡 面试技巧

### 技术面试技巧

#### 1. 回答问题的 STAR 法则
- **S**ituation: 背景
- **T**ask: 任务
- **A**ction: 行动
- **R**esult: 结果

#### 2. 代码题解题步骤
1. **理解题意**: 确认输入输出，询问边界条件
2. **举例说明**: 用具体例子理解问题
3. **思路讲解**: 先说思路再写代码
4. **编码实现**: 边写边解释
5. **测试验证**: 用 test case 验证
6. **优化讨论**: 时间/空间复杂度分析

#### 3. 不会的问题怎么办
- 不要说"不会"，说"这个问题我之前没遇到过，但我的思路是..."
- 展示思考过程比答案更重要
- 可以请求提示或降低难度

#### 4. 项目经验讲解技巧
- 用 STAR 法则
- 突出自己的贡献
- 准备技术难点和解决方案
- 准备性能优化数据
- 准备架构设计思路

---

### 避免的雷区

❌ **千万不要**:
- 说前公司/项目的坏话
- 说不了解就乱说
- 抢面试官的话
- 表现得不耐烦
- 说谎或夸大经历
- 对不会的问题直接说"不会"
- 回答问题跑题

✅ **应该做**:
- 谦虚但自信
- 展示学习能力
- 积极思考问题
- 主动沟通确认
- 保持良好心态
- 准备反问问题
